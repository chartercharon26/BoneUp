## 坐太久，它真的会变骨头

![原版从正常工作到逐渐变骨头的三个状态](original-sitting.png)

连续坐着，小动物会从脚开始慢慢变成骨头；站起来活动后，点 **STAND UP** 帮它恢复。提醒就在桌面角落，陪你把“该起来了”变成一件看得见的小事。
