## Install and choose English

### Mac

1. Extract the entire ZIP and open `BoneUp-Meow-1.3.dmg`.
2. Drag **BoneUp 喵** into **Applications** (the DMG shortcut may be labelled **应用程序**).
3. Open the app from Applications and look for **🐾** in the menu bar.
4. Choose **🐾 → 语言 / Language → English**.

On first launch the Mac app enables opening at login and creates Desktop / Dock shortcuts. Disable **Open at login** from the paw menu if desired. The download is ad-hoc signed, not Apple-notarized; review macOS Privacy & Security if it is blocked.

### Windows 10 / 11

1. Download the Windows ZIP and choose **Extract All**. Do not run it inside the ZIP.
2. Keep all folders together and run `install.bat`. It uses the local .NET Framework compiler to install the app.
3. The app starts after installation. You can reopen **BoneUp Meow** from the Desktop or Start menu.
4. Right-click the cat icon in the system tray, then choose **语言 / Language → English**.

The app installs to `%LOCALAPPDATA%\BoneUpMeow`. If the compiler is missing, install Microsoft .NET Framework 4.8 and try again. The ZIP includes an English / Chinese quick start and a Chinese illustrated Windows guide.
